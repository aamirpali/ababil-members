# Ababil Members

A clean WordPress membership & community plugin.

## Features
- Registration & login, Instagram-style profiles
- Member directory, followers, private messaging
- Facebook-style feed, groups, stories, notifications
- Login-aware menus, GDPR tools, 2FA, GitHub auto-update

## Installation
Upload the zip in WordPress → Plugins → Add New → Upload Plugin.

## Auto-updates
This plugin updates directly from GitHub releases.
